## 📋 Descrizione

Comprare la prima casa fa paura: tasse nascoste, clausole capestro, abusi edilizi non dichiarati, banche che non spiegano davvero come funziona un mutuo. **MutuoStep ti accompagna passo passo** — dal calcolo iniziale del budget fino alla firma del rogito — con strumenti operativi, checklist offline e gli avvisi critici di chi nel settore ci lavora da anni.

> Niente account, niente database, niente pubblicità. I tuoi dati restano sul tuo dispositivo. Sempre.

**Per chi è MutuoStep:**
- 🧑‍🎓 Giovani e Under 36 che stanno valutando la prima casa
- 👫 Coppie alla prima esperienza con il mutuo
- 🏘️ Chi vuole evitare gli errori classici della trattativa
- 🧮 Chi cerca uno strumento serio prima di parlare con la banca

## ✨ Cosa puoi fare con MutuoStep

### 💰 Calcolatore Budget intelligente
- **Tassi BCE live** dal Statistical Data Warehouse (aggiornamento mensile, fallback offline)
- Reddito netto, ISEE, età → applichiamo le **logiche bancarie reali**
- **Tasso Fisso vs Variabile** con segmented control e default precompilato
- **Slider durata** 5–40 anni, ricalcolo in tempo reale
- **Opzione Under 36 / Consap** attivata automaticamente al rispetto dei requisiti
- 6 voci di **costi accessori** dettagliate (registro, notaio, agenzia, perizia, istruttoria, assicurazione) — ognuna con tooltip che spiega cos'è
- **Verifica fattibilità** con due check colorati (capacità reddito + sostenibilità rata) e verdetto complessivo
- **Salva scenari multipli** in localStorage per confrontare ipotesi diverse

### 🛣 Roadmap del mutuo
- Le **6 fasi** del processo: predelibera → ricerca → proposta → compromesso → perizia → rogito
- Le **chicche del notaio** integrate: clausola sospensiva, lettura indipendente, registrazione del compromesso
- Tracciamento del progresso con timeline interattiva e dettagli espandibili

### ⌂ Checklist visita immobile
- **Aspetti tecnici**: umidità, tetto, infissi, impianti, classe APE
- **Domande strategiche**: bollette, spese straordinarie, esposizione solare
- **Verifiche burocratiche**: planimetria catastale, servitù, abusi
- **Multi‑immobile**: salva una checklist per ogni casa visitata
- Funziona **offline al 100%** durante il sopralluogo

### ▤ Wallet documenti
- L'elenco completo di **ciò che la banca ti chiederà** per la pratica mutuo
- Spunta i documenti man mano che li raccogli
- Suggerimenti su come ottenerli (CAF, INPS, agenzia, notaio…)

### 🚩 Red Flags
I 4 segnali di pericolo da non ignorare durante la trattativa:
- Eccessiva fretta del venditore
- Prezzo fuori mercato
- Casa proveniente da donazione
- Abusi edilizi nascosti

### ∑ Tabella costi accessori
Riepilogo dinamico di tutte le voci — Imposta di Registro, Notaio, Agenzia, Perizia, Istruttoria, Assicurazione — con stime per il tuo caso specifico.

## 🔒 Privacy dell'app

**MutuoStep non raccoglie nessun dato personale.** Punto.

| Dato | Raccolto? | Condiviso? |
|---|:---:|:---:|
| Reddito, ISEE, età | ❌ | ❌ |
| Scenari salvati | ❌ | ❌ |
| Checklist visite | ❌ | ❌ |
| Posizione | ❌ | ❌ |
| Contatti, foto, file | ❌ | ❌ |
| Identificatori dispositivo | ❌ | ❌ |
| Cronologia di utilizzo | ❌ | ❌ |

**Come funziona realmente:**
- Tutti i tuoi dati (reddito, scenari, checklist, wallet) vengono salvati nel **`localStorage` del tuo browser** e mai inviati altrove
- **Nessun account**, nessun login, nessuna registrazione
- **Nessun tracking** (no Google Analytics, no Meta Pixel, no fingerprinting)
- **Nessuna pubblicità**, nessun cookie di terze parti
- **Nessun database centralizzato** lato server

**Unica chiamata di rete in uscita:**
- `data-api.ecb.europa.eu` → per scaricare i tassi medi mutuo italiani dal Statistical Data Warehouse della BCE. È un endpoint pubblico e statistico, **non vengono inviati i tuoi dati personali**, solo una richiesta GET per i valori aggregati nazionali.

1. Apri MutuoStep nel browser
2. Cerca l'icona di **installazione PWA** ![install](https://img.shields.io/badge/⊕-install-blue?style=flat-square) nella barra degli indirizzi (a destra dell'URL)

## 🛠 Per gli sviluppatori

### Stack tecnologico
- **HTML / CSS / JavaScript vanilla** — zero dipendenze, zero build step
- **Service Worker** — strategia cache‑first per assets, network‑only per API esterne
- **localStorage** — persistenza locale di state, scenari, checklist
- **Web App Manifest** — installabilità come PWA
- **Fetch API** + **AbortController** — chiamate ECB con timeout
- **CSS variables** + `prefers-color-scheme` — dark/light mode automatico

### Avvio in locale

```bash
git clone <repo>
cd MutuoStep
python3 -m http.server 4173
# poi apri http://localhost:4173
```

Nessun `npm install`, nessun bundler, nessun framework.

### Endpoint dati live

```
https://data-api.ecb.europa.eu/service/data/MIR/{key}?lastNObservations=1&format=jsondata

Series:
  fisso     → MIR/M.IT.B.A2C.P.R.A.2250.EUR.N
  variabile → MIR/M.IT.B.A2C.F.R.A.2250.EUR.N
```

CORS aperto, JSON SDMX, nessuna API key. Cache lato client: 24h.
