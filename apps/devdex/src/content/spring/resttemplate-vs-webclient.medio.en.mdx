# RestTemplate vs WebClient — Intermediate patterns

## Timeouts and retry

```java
@Bean
public WebClient web(WebClient.Builder b) {
    HttpClient http = HttpClient.create()
        .responseTimeout(Duration.ofSeconds(3))
        .option(ChannelOption.CONNECT_TIMEOUT_MILLIS, 2000);
    return b.clientConnector(new ReactorClientHttpConnector(http)).build();
}
```

Retry with Reactor:

```java
web.get().uri("/flaky")
    .retrieve()
    .bodyToMono(String.class)
    .retryWhen(Retry.backoff(3, Duration.ofMillis(200))
                    .filter(ex -> ex instanceof IOException));
```

## Filter / Interceptor

Adding a header to every request:

```java
WebClient web = WebClient.builder()
    .filter((req, next) -> {
        ClientRequest authed = ClientRequest.from(req)
            .header("Authorization", "Bearer " + tokens.get())
            .build();
        return next.exchange(authed);
    })
    .build();
```

For RestTemplate, `ClientHttpRequestInterceptor` does the same job.

## Error handling

```java
web.get().uri("/orders/{id}", id)
    .retrieve()
    .onStatus(HttpStatusCode::is4xxClientError,
              resp -> resp.bodyToMono(ApiError.class)
                          .flatMap(err -> Mono.error(new OrderNotFound(err))))
    .bodyToMono(Order.class);
```

## Tests

- RestTemplate: `MockRestServiceServer` from `spring-test`.
- WebClient: mock `ExchangeFunction` or OkHttp's `MockWebServer`.

```java
ExchangeFunction stub = req -> Mono.just(
    ClientResponse.create(HttpStatus.OK)
        .header("Content-Type", "application/json")
        .body("{\"id\":1}")
        .build());
var web = WebClient.builder().exchangeFunction(stub).build();
```

## Connection pool

- RestTemplate (Apache HttpClient): pool with
  `PoolingHttpClientConnectionManager`.
- WebClient (Reactor Netty):
  `ConnectionProvider.builder("custom").maxConnections(100)...`

> ⚠️ Without tuning, the default **strangles** you under load. Always measure.
