# Sincrono vs Asincrono

**Sincrono**: chiami una funzione, attendi il risultato, prosegui.

```java
String html = http.get("https://example.com");  // bloccante
process(html);                                  // parte solo quando html è pronto
```

**Asincrono**: chiami una funzione, ti dà un "biglietto" (Future, CompletableFuture,
callback). Il thread continua a fare altro; quando il risultato è pronto, viene
notificato.

```java
CompletableFuture<String> cf = http.getAsync("https://example.com");
cf.thenAccept(this::process);   // process verrà chiamato quando html arriva
// nel frattempo questo thread fa altro
```

## Perché ci interessa?

- **Performance**: il thread non resta inattivo ad aspettare l'I/O.
- **Scalabilità**: con poche thread (es. il loop di Netty) servi migliaia di richieste.
- **UX**: in un'app desktop/mobile non blocchi la UI.

## Future (Java 5)

```java
ExecutorService ex = Executors.newFixedThreadPool(4);
Future<Integer> f = ex.submit(() -> heavyComputation());

// fai altro...
int result = f.get();   // bloccante se non ancora pronto
```

`Future` è limitato: non si può "concatenare" né combinare facilmente con altri. Da qui
nasce `CompletableFuture`.
